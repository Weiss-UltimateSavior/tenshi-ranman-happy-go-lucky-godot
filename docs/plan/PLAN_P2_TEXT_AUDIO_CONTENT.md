## 2. P2-B BGM 无缝循环:`.sli` 支持(0.5 天)

### 2.1 格式(实测样例 `assets/bgm/bgm54.ogg.sli`)

```text
#2.00
# Sound Loop Information (utf-8)
# Generated by WaveLoopManager.cpp
Link { From=4917760;          To=1268096;          Smooth=False; Condition=eq; RefValue=0;          CondVar=0;  }
Label { Position=3080192;          Name='sabi';                                      }
```

`From`/`To` 为**采样点**(与 `ogg.sli` 同名的 ogg 的 PCM 采样位置),
`Condition=eq` 配合 `CondVar/RefValue` 表示条件循环(仅变量等于值时才循环);
`Smooth=True` 时需交叉淡化。

### 2.2 实施步骤

1. [x] 新增 `scripts/story/sli_parser.gd`(RefCounted):解析 `Link{...}` 与
   `Label{...}`;字段用正则提取,`Condition`/`RefValue`/`CondVar` 保留原始值
2. [x] `AudioManager.play_bgm()`:播放前尝试读 `<ogg>.sli`;
   若存在 `Link` 且条件满足 → 设置
   `AudioStreamOggVorbis.loop_begin/loop_end`(采样→秒:`/ 采样率`)并 `looping = true`
3. [x] 条件循环评估:`Condition=eq` 时比较 `CondVar`(游戏变量名,如 H 场景标志)
   与 `RefValue`;变量来源是 SCN 的 flag/系统变量 —— **首版只处理无条件 Link**
   (`Condition=eq` + `CondVar=0` + `RefValue=0`,即恒真),其余记录 warning
4. [x] 缓存放 `stream_cache` 的 key 里带上 sli(mtime 或 hash),避免改 sli 不生效
5. [x] 文档:`docs/sli_loop.md` 记录格式、条件语义、当前支持的子集

### 2.3 验证

- [ ] `tools/qa_bgm_loop.gd`:断言 `bgm54.ogg` 播放后
  `loop_begin ≈ 1268096/48000 ≈ 26.4s`、`loop_end ≈ 4917760/48000 ≈ 102.5s`
  (以实际 ogg 采样率为准)
- [ ] 人工听感:标题 BGM 循环处不应有断点(原版是 sabi 段落循环)

2. **1440 画布被压扁** — `scnchart`/`window`/`window_h` 的 PIMG 高 1440，
   编译产物按它算 `ui_scale`，y 缩放变成 0.5（"错位"）。原始依据
   `config.tjs`:`scHeight=1080` 而 `exHeight=1440` 只是出血区。
   新增 `presentation_size()` 并把 3 个 JSON 就地修正。
3. **`func,visible,false` 设计样板被画出来** — `scnchart.func` 对每类图表元素
   都声明了 `visible,false`（原版运行时克隆它们），静态层照画导致右侧
   「Update」弹窗与节点样板互相叠压。新增
   `_func_template_layer_path()`；同类规则也修正了 `cgviewlist`/`quickmenu`/
   `extra_stand` 各一处。
4. **流程图节点区是手写坐标** — 旧代码 `Rect2(640, 185 + i*92, ...)` 与 ini 无关。
   改为 `section`/`subsection` 模板 + `default.tjs` `step:(100)` 行距，
   行栈在 `#scroll` (576,0,896,982) 内居中并裁切；页签用 `_route` 原型槽位，
   滑块用 `slider:rect`，预览用 `playback:text:rect`；并移除重复的
