# 天神乱漫 Happy GO Lucky!! — Godot 工程

Godot 4.6 迁移/重构工程源码。

> 本仓库只包含代码、场景和工程配置；游戏原始资源（图片 / 音频 / 视频等，约 7 GB）
> 不纳入版本控制。

## 目录结构

- `scenes/`：场景
- `scripts/`：GDScript 源码
- `tools/`：开发与 QA 工具
- `docs/`：迁移与兼容性文档

## 运行

1. 将游戏原始资源放回本地 `assets/` 目录（文件与
   `docs/restored_structure_manifest.tsv` 中记录的结构一致）。
2. 使用 Godot 4.6 打开 `project.godot`。
